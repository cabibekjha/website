How to get your access key (one time)
  1. On github.com, click your profile picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name it "Website admin" and set an expiry (for example 1 year).
  3. Under Repository access, choose Only select repositories and pick your website repository.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it, and paste it above. Don't share it with anyone.
